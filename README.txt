HYDERABAD INTERACTIVE MAP — STARTER FILES

Folder contents:
- index.html: map page
- style.css: page styling
- script.js: map layers, legend and clickable grid cells
- data/Hyderabad_Interactive_Map_Data.geojson: web-ready grid data

To use:
1. Keep the folder structure exactly as supplied.
2. Open index.html only after starting a local web server, or publish this folder through GitHub Pages.
3. Leaflet and the basemap require an internet connection.

Map layers:
- New built-up area (%)
- Tree-classified loss (%)
- Land surface temperature change (°C)

Interpretation:
Dynamic World tree class is not equivalent to legally/ecologically defined forest cover.
LST is land surface temperature, not air temperature.
Spatial patterns do not establish causality.
